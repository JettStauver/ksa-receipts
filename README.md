# KSA Receipts

Claude plugin used by the team at KS Analytical Systems. This repository is a plugin marketplace with one plugin.

| Plugin | What it does |
|---|---|
| [`ksa-receipts`](plugins/ksa-receipts) | Files Gmail receipts and invoices into the KSA shared drive by year and category, with a yearly report, nightly runs and a resumable backfill. |

**Team members:** follow [SETUP.md](SETUP.md).

These plugins only work with access to KSA's Google Workspace. Nothing company-specific (addresses, card details, data) is stored here.

Maintainers: see [RELEASING.md](RELEASING.md) and [CHANGELOG.md](CHANGELOG.md).
